Settings

Where RamCapper keeps its data, and the permissions it runs with.

Data folder

Where RamCapper keeps history.db (memory history, events, devices) and config.json (limits, switches).
Current location–
Your history and settings are copied to the new folder (existing data there is never overwritten), then RamCapper restarts itself. The old files are left in place.

Administrator access

Windows will show its permission prompt. Admin lets RamCapper trim, cap and end elevated and system processes, see more connections, and create network limits.

About

Only one copy of RamCapper runs at a time. Starting it again just brings the existing window to the front. A newer version replaces an older one that is still running.
