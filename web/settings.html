Settings

Where RamCapper keeps its data, and the permissions it runs with.

Install RamCapper

 
Restart RamCapper with administrator rights (Windows asks for permission).
Start with Windows
Adds a RamCapper shortcut to your Windows Startup folder so it opens hidden in the tray when you sign in. Off by default – works for the portable copy too.

Data folder

Where RamCapper keeps history.db (memory history, events, devices) and config.json (limits, switches).
Current location–
Your history and settings are copied to the new folder (existing data there is never overwritten), then RamCapper restarts itself. The old files are left in place.

Administrator access

Windows will show its permission prompt. Admin lets RamCapper trim, cap and end elevated and system processes, see more connections, and create network limits.

Dashboard window

Open the dashboard maximized every time it starts or is reopened from the tray. Turn this off to use a normal-sized window.

Notch stats bar

A one-line notch that hangs from the top edge of your screen with live RAM, total CPU, GPU, download and upload speed and your biggest app. Click it to bring the dashboard back; right-click for a menu. It pulses red when memory is critical and flashes limiter actions.

Shortcuts & pinning

Open RamCapper from the Start menu or desktop, or pin it to the taskbar.
Start menu
Adds RamCapper to your apps list, so it shows up when you search Start.
Desktop
A RamCapper icon on your desktop.
Taskbar
Windows doesn't allow apps to pin themselves. Add the Start menu shortcut, then press Start, type RamCapper, right-click it and choose Pin to taskbar.

About

Only one copy of RamCapper runs at a time. Starting it again just brings the existing window to the front. A newer version replaces an older one that is still running.
